# Phase 5 — Experiment Design

## 1. Frozen benchmark

- File: `reports/phase5/fixtures/phase5_heldout_v1.json`, SHA-256 `98307FED1FFF199F3447319428C8802C03C10511898EE4FCA553D8EF55C8DBE7`
- 300 tasks, 15 categories × 20, across 3 suites (A self-improvement/temporal/recovery,
  B intelligence/contradiction/ambiguity, C engineering/security/reliability).
- Generated by `harness/generate_tasks.py` with a fixed seed (20261023) → reproducible;
  validated (gold in gold evidence, forbidden absent, unique ids, per-project isolation,
  lexical-matchable retrieval queries).
- Frozen before any comparative run. Task difficulty was not changed after inspecting
  results (the only post-calibration change was fixing the C1 prompt to include the source
  and repairing the abstention-biased system prompt; both are harness fixes, documented).

## 2. Arms

| ID | Configuration | Retrieval | Context selection |
|---|---|---|---|
| A | No memory | — | — |
| B | Original Beacon `99c70908` | CLI lexical | none |
| C | V6 semantic | `SearchHybrid` hashed (offline) | none |
| D | V6 intelligent | `SearchHybrid` hashed | `SelectTrustContext` (all + sufficiency) |
| E | Oracle | gold required-evidence | — |

Feature flags verified in code: C uses `SearchHybrid{LexicalWeight:0,SemanticWeight:1}`;
D adds `SelectTrustContext{supersession,trust,conflict,injection,sufficiency,withhold}`.
B uses the untouched original binary's `memory list` (lexical). No invented capabilities.

## 3. Controls

- Same model (qwen2.5-coder:7b), system prompt, tools (none), K=8, context budget, and
  deterministic grading for every arm; only the memory evidence differs.
- Retrieval query (`retrieval_query`) is terse key terms present in the gold evidence, so
  the lexical original arm is not structurally excluded; the agent `request` is natural.
- Each task has a unique project; fresh DB per (task, arm); no cross-arm state.
- Gold/forbidden/rubrics never placed in the agent prompt.

## 4. Repetition protocol

`temperature=0, seed∈{0,1,2}`. Seeds 1–2 were run on a 100-task discriminating subset and
produced **byte-identical** results to seed 0 (the model is deterministic at temperature 0).
Effective unique trials = 1; this is recorded rather than treated as 3 independent trials.

## 5. Grading (objective)

| answer_type | Grader |
|---|---|
| value / set | gold token(s) present AND no forbidden token |
| abstain | abstention/refusal phrase present AND no forbidden token |
| source | gold + source token present, no forbidden |
| code | extract ```python block, run hidden unittest |

Forbidden tokens encode the wrong-memory answer, so a confident wrong answer is a false
acceptance. Security leaks = forbidden token present in a security task.

## 6. Compute

300 tasks × 5 arms × 1 seed = **1,500 executions** (+1,000 for the seed subset). Bounded,
local, no paid resources. 1M-memory and 32/64-client matrices were not run (host limits).

## 7. Anti-contamination

- Held-out tasks disjoint from Phase 4C/4D fixtures (different projects, entities, values).
- Harness tuned only on the calibration subset (`raw/calibration*.json`).
- Frozen fixture hash recorded; raw traces preserved per run in `traces/`.
- No task was silently replaced after a loss.
